# Open Source Roadmap

## v0.1 (Current MVP)
- [x] Mock stock and news producers
- [x] Redpanda streaming pipeline
- [x] Feature computation and anomaly detection
- [x] News correlation engine
- [x] FastAPI REST API
- [x] MCP server with 13 tools
- [x] Docker Compose local stack
- [x] Prometheus metrics

## v0.2
- [ ] Optional real market data adapters (Alpha Vantage, Polygon)
- [ ] Embedding-based news similarity (`news_embeddings` topic)
- [ ] Grafana dashboards
- [ ] WebSocket live quote streaming

## v0.3
- [ ] Agent skill packaging for Cursor / Claude
- [ ] Multi-tenant symbol watchlists
- [ ] Historical replay mode from CSV/archive

## v1.0
- [ ] Production hardening (auth, rate limits)
- [ ] Kubernetes Helm chart
- [ ] Cloud deployment guides (AWS MSK, Confluent Cloud)

## Non-Goals

- Stock price prediction
- Trading signals or financial advice
- Automated order execution
